## 1. 产品定位

### 1.1 核心价值

**名称**：Mindmap PPT Editor

**核心价值**：让不懂编程的用户也能轻松制作可播放的思维导图PPT

**目标用户**：有基础电脑操作能力的用户（会用Word、PPT等办公软件，能理解基本的文件操作，但不懂编程）

**技术方案**：纯前端静态HTML，用户双击即可使用

### 1.2 核心功能

| 功能 | 说明 |
|------|------|
| AI生成 | 输入主题或文档，AI生成思维导图 |
| 完全编辑 | 用户可自由编辑每个节点的文字、添加/删除节点 |
| 图片管理 | 支持本地上传图片 + AI生成图片 |
| 实时预览 | 编辑时右侧实时显示效果 |
| 本地存储 | 浏览器自动保存 + 文件导入导出 |
| HTML导出 | 导出为可播放的HTML文件 |

## 2. 用户需求

### 2.1 目标用户

- 有基础电脑操作能力的用户
- 会用Word、PPT等办公软件
- 能理解基本的文件操作
- 不懂编程

### 2.2 用户自主权

**完全控制**：用户可以手动编辑每一个节点的文字、添加/删除节点、选择每张图片

### 2.3 使用方式

**双模式支持**：既能从零生成（输入主题，AI生成思维导图），也能从文档转换（上传现有文档，AI提取内容生成思维导图）

### 2.4 图片来源

**两者都支持**：既能上传本地图片，也能让AI生成

### 2.5 分享方式

**本地文件导出**：导出为HTML文件，用户可以手动发送给他人，主要是用户本地使用和展示

### 2.6 API策略

测试版提供API，后续用户扩大再更改策略

### 2.7 工作流程

**灵活起点**：用户可以从预设模板开始修改，也可以从零开始输入内容

### 2.8 用户界面

- 刚开始有向导式教程
- 后续用户可以自主选择是否关闭
- 不管什么时候每一步都可以自由编辑

### 2.9 预览方式

**实时预览**：编辑时右侧实时显示效果

### 2.10 数据存储

**两者都支持**：既支持浏览器本地存储，也支持文件导入导出

### 6.6 AI调用接口

```javascript
// 统一的AI调用接口
async function callAI(prompt, options) {
  const { aiProvider, aiModel, apiKey } = options;
  
  switch (aiProvider) {
    case 'mimo':
      return await callMimo(prompt, apiKey, aiModel);
    case 'qwen':
      return await callQwen(prompt, apiKey, aiModel);
    default:
      throw new Error(`不支持的AI服务商: ${aiProvider}`);
  }
}

// Mimo API调用（兼容OpenAI格式）
async function callMimo(prompt, apiKey, model) {
  const response = await fetch('https://token-plan-cn.xiaomimimo.com/v1/chat/completions', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${apiKey}`
    },
    body: JSON.stringify({
      model: model,
      messages: [
        { role: 'system', content: '你是一个专业的思维导图生成助手。' },
        { role: 'user', content: prompt }
      ],
      temperature: 0.7,
      max_tokens: 2000
    })
  });
  
  if (!response.ok) {
    throw new Error(`Mimo API调用失败: ${response.statusText}`);
  }
  
  return await response.json();
}

// 通义千问API调用
async function callQwen(prompt, apiKey, model) {
  const response = await fetch('https://dashscope.aliyuncs.com/api/v1/services/aigc/text-generation/generation', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${apiKey}`
    },
    body: JSON.stringify({
      model: model,
      input: {
        messages: [
          { role: 'system', content: '你是一个专业的思维导图生成助手。' },
          { role: 'user', content: prompt }
        ]
      },
      parameters: {
        temperature: 0.7,
        max_tokens: 2000
      }
    })
  });
  
  if (!response.ok) {
    throw new Error(`通义千问API调用失败: ${response.statusText}`);
  }
  
  return await response.json();
}
```
